Privacy policy

What ELIX uses

ELIX explains content you choose on a webpage. It runs on webpages where you grant it access so it can detect selections and show its controls.

When you request an explanation, ELIX sends selected text and, when available, a short excerpt of relevant surrounding text to OpenAI. If you enable Media input and select a region, ELIX captures the visible tab locally, sends only the crop you select and any relevant media description, and discards the full screenshot. The request includes the model and the age or custom persona you choose.

API key and preferences

You provide your own OpenAI API key. ELIX stores it and your preferences in browser extension storage. On Chrome, that storage can sync across devices when browser sync is enabled. ELIX sends the key to OpenAI to authenticate your requests. You can remove the saved key from Settings.

OpenAI processes your requests under its own policies and the settings on your account. API requests may incur charges to your OpenAI account. OpenAI Privacy Policy

Use and sharing

ELIX uses the webpage content it receives to provide the explanation you requested. ELIX has no separate server for receiving your selections or API key and does not sell this data or use it for advertising.

ELIX’s use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Chrome Web Store Limited Use policy

Questions

For privacy or support questions, use the ELIX repository. Keep API keys and private page content out of public issues.
