# ELIX

Browser extension that explains highlighted text at a chosen level — like you're 5, 10, 15, 20, or a freeform age/style.

## Status

Early setup. Local git initialized; extension scaffold coming next.

## Planned behavior

1. Highlight text on any page
2. Overlay appears with explanation level options
3. Selected text is sent to an LLM (BYOK via extension options)
4. Explanation shown in the overlay
